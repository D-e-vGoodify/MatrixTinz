# MatrixTinz 
<p align="center">
  <img src="assets/icon-foreground.png" alt="App Icon" width="80%" />
</p>

A FOSS modern android app with a clean UI, made to bring a fun and user preferred experience to Calculations 😄. This is the first version of the app and I look forward to adding a lot more useful features as the journey goes ❤️
<br>
There's also a [website](https://matrixtinz.web.app), although the website is made with firebase so its not completely open-source, but that's just for the website, the app is fully open source
